# R19 Android Compatibility

The raw Assignment read preserves `g900`, `g1800`, `u900`, `u2100`, `l900`, `l1800`, and `l2100`. Mobile image and finish logic interpret them as sector-loop maxima. Synchronization would therefore change Android work-card and Cell expectations.

Compatibility is blocked because the available evidence does not prove active Assignment refresh, cache invalidation, local-edit reconciliation, or count-decrease behavior. Contract tests alone are insufficient. No mobile route, payload, APK, or Android code was changed.
