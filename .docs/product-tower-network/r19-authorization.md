# R19 Authorization

Current proven policy:

- active users with exact `/assignment` privilege may view Tower workspace and Assignment snapshots;
- strict administrators may create/edit/import Towers through server routes;
- Riggers are not Tower editors;
- no Coordinator Tower-edit or synchronization scope is proven.

Future R19 Tower edit and synchronization must remain administrator-only until a narrower existing scope is evidenced. Every API must resolve identity and active status server-side. No new role is approved.
