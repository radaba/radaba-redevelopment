# Final Radaba platform guide

This is the long-term maintenance entry point for the Next.js redevelopment. M14R performed a conservative decommission review: production-facing compatibility routes, their security/observability wrappers, contract tests, and recovery controls remain because no route-level zero-usage evidence exists. Historical phase documents are archived logically in place and remain searchable.

Start with architecture and API reference; then security, database, deployment, operations, maintenance, and troubleshooting. Production behavior and schema were not changed by M14R.
