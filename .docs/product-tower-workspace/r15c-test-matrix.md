# R15C test matrix

Pure tests cover numeric sector and stable band ordering, multiple bands without merging,
missing groups, duplicate keys/business identifiers, valid and invalid coordinates,
contradictory sector flags, incomplete/unknown images, unresolved Assignment context,
conflicting people, timeline use of populated timestamps, bounded repository source checks,
route authorization/states, responsive table/cards, and navigation links.

R15A extraction regressions and existing Tower/Assignment/mobile compatibility suites remain
the broader regression boundary.
